C2RMF — Centre for Research and Restoration of the Museums of France
This GitHub repository hosts the code for the C2RMF’s data processing, software development, and scientific engineering projects.

Development of software for the acquisition, processing, and visualization of scientific data.
Use of imaging and spectral analysis tools (hyperspectral imaging, XRF, RIS, LIS, IBA, etc.).
